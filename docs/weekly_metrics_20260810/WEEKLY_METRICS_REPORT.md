## 结果边界

- 模仿精度是冻结历史态势离线回放的一致性，不是真实同场景复现或运行安全证明。
- 意图类型准确率衡量大类识别；完整意图框架准确率还要求动作与必需参数槽位正确。
- 意图类型F1同时惩罚漏检和多报；90.73%的参考意图命中率不惩罚额外预测，不能单独作为正式准确率。
- 意图评估不包含语音识别误差，参考标注尚不能宣称为独立人工双盲金标准。
